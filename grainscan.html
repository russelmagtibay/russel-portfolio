GrainScan — Automated Rice Quality Inspection
Overview

What GrainScan Does

GrainScan is a capstone thesis project that automates the process of rice grain quality inspection using computer vision. Traditional inspection is done manually and is slow and inconsistent. GrainScan uses a trained YOLOv9 model to detect, classify, and measure individual rice grains in milliseconds.

The system can analyze a still image or grab frames from a live camera feed, then generate a detailed quality report showing grain composition and an overall quality grade.

Key Features

Application Features

  • 👁️
    Grain Detection & Classification — YOLOv9 model identifies and classifies each grain by type (Long, Medium, Short, Broken, Discolored) in real time.
  • 📊
    Quality Scoring — Automatically computes an overall sample grade (High / Medium / Low) based on grain composition ratios.
  • 🖥️
    Desktop GUI — Clean Tkinter interface for scanning images, viewing analytics, exporting reports, and training/fine-tuning models.
  • 📷
    Live Camera Capture — Snap frames from a connected camera and run the same full analysis pipeline in real time.
  • 📄
    Report Export — Generate and export detailed inspection reports with grain counts, percentages, and quality grade.
  • 📦
    Windows Installer — Packaged with PyInstaller + Inno Setup for easy distribution as a standalone Windows executable.
